# Security Policy

## Supported versions

Security fixes are applied to the current public release line.

| Version | Supported |
|---|---|
| 0.4.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature from the repository's **Security** tab. Do not open a public issue for a vulnerability that could expose credentials, private QLab workspace information, or another user's system.

OSC passcodes are intended to remain in process memory only. A report that suggests a passcode is stored, logged, transmitted somewhere other than QLab, or exposed through diagnostics should be treated as security-sensitive.
